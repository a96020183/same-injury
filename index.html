What you are watching

      
Recorded, with evidence
Case outcomes and trace events come from the repository’s recorded live runs. Query results come from the bundled SQL recordings. Receipt metadata was regenerated offline and checked against those recordings; it is labelled in every receipt.
The original product uses Zetaris for evidence and access control, Nightshift for model calls, and the Meterless World Model for shared state and identity proposals.
Decisions stay in the recording
This website makes no model calls, sends no queries, and performs no approvals. The later snapshot shows automatic operator approvals already in the trace; they were not a human review. Missing post-review receipts are labelled as not included.
A State Plan label means its own records were outside the federal file searched. “Not found” describes only the listed searches, never an employer’s reporting conduct.
